# Counterfactual Reasoning for Robust Visual Question Answering

This repository contains the official implementation of the paper **"Counterfactual Reasoning for Robust Visual Question Answering"**.

This code is built upon the [CSS-VQA](https://github.com/yanxinzju/CSS-VQA) and [CL-VQA](https://github.com/liangzujie/CL-VQA) frameworks, introducing a novel Batch-Contrastive loss, Answer-Contrastive loss, and Gradient-Discrepancy loss within a curriculum training strategy.

## Data Setup

### 1\. Download Raw Data

```bash
bash tools/download.sh
```

This downloads:

  - GloVe word embeddings (6B tokens, 300d)
  - VQA-CP v1/v2 datasets
  - VQA v2 dataset

### 2\. Process Data

```bash
bash tools/process.sh
```

This generates:

  - Vocabulary dictionary (`data/dictionary.pkl`)
  - Answer label mappings
  - Soft scores for answers
  - GloVe embedding initialization file

### 3\. Download Image Features

Download pre-extracted image features to `data/rcnn_feature/`:

  - One `.pth` file per image, named `{image_id}.pth`
  - Each file contains a dict with key `'image_feature'` (numpy array of shape `(36, 2048)`)
  - Features can be obtained from the [bottom-up-attention](https://github.com/hengyuan-hu/bottom-up-attention-vqa) repository.

### 4\. Download Additional Files

Download the following files (not generated by scripts):

  - Hint scores: `data/train_cpv2_hintscore.json`, `data/test_cpv2_hintscore.json`, etc.
  - Answer embeddings: `data/answer_embs_ac.npy`, `data/answer_embs_ac_v2.npy`
  - Question type masks: Files in `util/` directory (`qid2type_*.json`, `*_type_mask.json`, `*_notype_mask.json`)

These files can be obtained from the original [CSS-VQA](https://github.com/yanxinzju/CSS-VQA) repository.

## Training

To train the model with the proposed settings (Batch-Contrastive, AC Loss, GD Loss):

```bash
CUDA_VISIBLE_DEVICES=0 python main.py \
  --dataset cpv2 \
  --output exp_name \
  --contras_loss_type new \
  --use_ac_loss \
  --use_gd_loss
```

Or use the provided script:

```bash
bash run.sh
```

Key arguments:

  - `--dataset`: Choose from `cpv2`, `cpv1`, or `v2`
  - `--output`: Experiment name (saved in `logs/`)
  - `--use_wandb`: Enable Weights & Biases logging
  - `--contras_loss_type`: `new` for Batch-Contrastive (Ours), `old` for original CL.
  - `--use_ac_loss`: Enable Answer-Contrastive Loss.
  - `--use_gd_loss`: Enable Gradient-Discrepancy Loss.

See `main.py` for all available arguments.

## Evaluation

```bash
CUDA_VISIBLE_DEVICES=0 python eval.py \
  --dataset cpv2 \
  --model_state logs/exp_name/model.pth
```
